# Gaze 0.6alpha

- Adds Transcribe screenshot sessions with ZIP export, Undo, and retry after export failure.
- Opens Transcribe at the menu position, with a bottom-right default, and matches its window frame to the menu.
- Makes the default tray menu compact and moves recordings behind a folder icon.
- Adds a header power icon to quit Gaze.
- Makes the Transcribe cross finish like Done, preserves Done hover colors, and restores the active window on tray left-click.

Windows x64 MSI includes the .NET desktop runtime and private FFmpeg/FFprobe. Encoder corresponding source and SHA256 checksums accompany the installer.

Validation: all 46 core checks and the Transcribe UI check pass. Full clean-device installation, upgrade, repair and uninstall, and broader GPU/DPI/multi-monitor testing remain outside this alpha's validation. The installer is unsigned.
